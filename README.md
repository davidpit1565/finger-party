# Finger Party — Working Project

> Working repository name only. The final product name is not approved yet.

An iPhone-first, offline-capable social finger-selection game. The core experience is a fair multi-touch random picker with a distinctive animated selection sequence. Optional party modes may follow after the core experience is validated.

## Product principles
- Finger Picker is the primary feature and remains free.
- No account or backend in the MVP.
- English-only launch.
- Fair random selection: the random winner is determined independently of the visual animation.
- Age-appropriate content and privacy-by-design.
- No ads or analytics in the MVP.
- Do not lock the core picker behind a paywall.
