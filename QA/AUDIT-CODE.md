# Code audit: Finger Picker (read-only review)

Scope: PRODUCT-SPEC §4-§8, §11, §13; TECHNICAL-PLAN; all of `App/Sources`, `Packages/FingerPickerCore/Sources`, tests, `project.yml`, privacy manifest.
Method: reading only (Linux, no compiler or device). "Confirmed" means the failure follows directly from the code, or from arithmetic I did on the palette. "Plausible" means it depends on UIKit/SwiftUI behaviour I could not run.

## Checked and found fine

- **Fairness.** `RoundController.lock()` is the only caller of `SelectionEngine`. It runs once per round on the frozen, id-sorted set, with a uniform `Int.random(in:using:)` over `SystemRandomNumberGenerator`. The `Round` (winnerID, point, colour) is immutable. `SelectorRoute` is built backward from the known winner. Colour, order and position cannot influence the choice. Duplicate ids and counts under 2 are rejected. The DEBUG `FixedIndexPicker` is behind `#if DEBUG`.
- **Touch identity.** Ids are monotonically increasing from a static counter and never reused. `UITouch` objects are not retained, only `ObjectIdentifier` keys. Began, moved, ended and cancelled are all handled. `isMultipleTouchEnabled = true`.
- **Coordinate space.** Rings, the takeover and `TouchCaptureUIView` live in the same `GeometryReader` ZStack under `.ignoresSafeArea()`. `geo.size` equals the UIView bounds. Normalization is done against `bounds`. The overlay controls respect safe areas, so there is no notch or Dynamic Island overlap in portrait. Marker positions are not animated (the animation value is the id list only), so rings track the finger without lag.
- **Reveal geometry.** `coverRadius` is the farthest-corner distance, plus 24pt margin. The circle scales from the winner point and covers the full surface, with no seam. The origin is stable. `WinnerTakeoverView` gates `onCompleted` with `completed`, and `revealCompleted()` is guarded to `.revealing`.
- **State machine.** The timer is invalidated whenever `needsTicks` is false. `startReveal` is idempotent (`selectorTask == nil`). The selector Task is cancelled in `interrupt`, `replay` and `revealCompleted`. A new touch during settling or countdown restarts the settle timer. Late touches go to `heldAfterLock`, so replay needs every old finger lifted. `replay()` is gated. `MainActor.assumeIsolated` is used only in callbacks that really run on the main queue or run loop. Timer and observer closures capture `[weak self]`, so there is no retain cycle.
- **Lock-frame touches.** Timer and touch events are serialized on the main thread, so a touch is either before the lock (included) or after (held, ignored). There is no double-lock path.
- **Reduce Motion.** The route is reduced to a 0.3s step with no ticks. The takeover becomes a 0.35s fade of the full circle. Rings do not pulse. The same stored winner is revealed.
- **Settings.** Defaults are sound off and haptics on. Persisted with `@Observable` stored backing, consistent with the toggles. The sheet is dark with Done and an `inline` title. Privacy link and version are present. No Form needlessly shows extra sections.
- **Haptics failure handling.** Core Haptics errors nil the engine and fall back to UIKit generators. A missing engine is a silent no-op. `stoppedHandler` and `resetHandler` rebuild lazily.
- **Info.plist and project.** iPhone-only. Portrait plus both landscapes (no upside-down). Status bar hidden both in Info.plist and in SwiftUI. Dark UI style forced. `ITSAppUsesNonExemptEncryption` is NO. Deployment target is iOS 17.0 (needed for `@Observable`). Bundled sounds `tick.wav` and `win.wav` are present. `SoundService` finds them flat or in `Sounds/`.
- **Privacy.** There are no network calls, no SDKs, and no persistence of coordinates. The UserDefaults reason code is declared. (See A3 for the missing boot-time API.)
- **Rotation.** The round is cancelled on a bounds change (allowed by spec §6/§11). `activeTouches` is cleared, so fingers held across a rotation cannot become participants.
- **Tests.** `TestSupport` and the model tests cover the state machine. Nothing tests `prefersDarkText` thresholds (A1 would not break existing tests).
